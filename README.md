## 💡 المميزات الهندسية للبرنامج
* **محاكاة شاملة لقدرات المكيفات (9000 ~ 24000 BTU):** معايرة دقيقة لجهد الـ DC Bus، تيار الذروة، التردد (Hz)، وجهد الأوجه الثلاثة (U-V-W) مع مقارنة وسيلتي التمدد (`Capillary` / `EEV`).
* **مقارنة 5 أنظمة لكروت الإنفرتر:** تحليل سلوك كروت المدى الواسع (`90V Ultra-Wide`) مقابل الكروت القياسية (`130V`, `155V`, `165V`, `185V`) في حالات خنق التردد (`Derating`) وفصل الحماية (`UVLO` / `OVLO`).
* **مؤشر الإجهاد الحراري ورادار الأعطال:** مراقبة حية لحرارة أيسي القدرة (`IPM`) ومكثفات الـ `DC Bus` الكيميائية وتوقع الأعطال الإلكترونية.
* **المشخّص الميداني وبطاقة تعريف الكارت الذكية (26 ماركة × 4 قدرات):** قاعدة بيانات متكاملة لأكواد الأعطال، أرقام البوردات، المعالجات (`MCU/DSP`)، وأيسيهات القدرة (`IPM`).
* **مختبر الأفوميتر التفاعلي:**
  * فاحص حساسات الحرارة (`NTC Sensor Lab`) لحساب المقاومة بالكيلو أوم والفولت على السوكيت.
  * فاحص توازن ملفات الضاغط (`U-V-W Winding Balance Checker`).
* **استوديو الكاميرا وبوستر التوثيق الهندسي (AR Diagnostic Poster):**
  * التعرف التلقائي وإظهار المستطيلات الحسابية والتشخيص الميداني بثلاث لغات (`العربية` / `Français` / `English`).
  * دعم التكبير والتصغير باللمس بإصبعين (`Pinch-to-Zoom`)، التحريك بالسحب (`Touch & Drag`)، وأزرار الأسهم.
